# TaskFlow DevOps Platform

## Overview

This project demonstrates a production-style DevOps implementation for OpenProject using GitHub Actions, Docker, Ansible, Terraform, Nginx, Prometheus, and Grafana.

## Objectives

- Automate application deployment
- Implement CI/CD
- Containerize applications
- Configure monitoring
- Apply Infrastructure as Code
- Practice production deployment workflows

## Technology Stack

- Ubuntu Server 24.04
- GitHub
- GitHub Actions
- Docker
- Docker Compose
- Nginx
- Ansible
- Terraform
- Prometheus
- Grafana
